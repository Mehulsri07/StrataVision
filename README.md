# StrataVision

StrataVision builds a proposed picture of the ground under the whole of Lucknow from the borewells
recorded in [StrataField](https://github.com/Mehulsri07/StrataField): what the layers probably are
at any spot, along any line and across the city, and how sure that is. The picture is worked out
again from the records every time, so it improves as borewells are added.

It is a separate Windows app that reads StrataField's records and never changes them. StrataField
must be installed and have borewells in it first.

The design is in [docs/superpowers/specs](docs/superpowers/specs/2026-10-13-stratavision-design.md).
